### ?? Animações
- **fadeInUp**: Entrada suave de elementos
- **slideInLeft**: Timeline items
- **pulse**: Marker de formação atual
- **shimmer**: Efeito brilho em progress bars
- **gradientShift**: Animação de gradientes
- **cardRotate**: Efeito cónico em hover
- **float**: WhatsApp button flutuante

### ?? Responsividade
- Breakpoints otimizados (1024px, 768px, 576px, 480px)
- Grid adaptativo em todos os componentes
- Tipografia fluida com `clamp()`
- Menu mobile com hamburger animado
- Touch-friendly em dispositivos móveis

### ?? Performance
- Uso de `backdrop-filter` para glassmorphism
- Animações GPU-accelerated
- Transições suaves com cubic-bezier
- Lazy loading de animações
- CSS otimizado com custom properties
