## Projectos em destaque

### FinancasCasa

Aplicação web para gestão de finanças domésticas, desenvolvida com **ASP.NET Core**, **Razor Pages**, **Entity Framework Core** e **ASP.NET Core Identity**.

O projecto tem como objectivo ajudar na organização de despesas, categorias, anexos e informação financeira familiar, com uma abordagem prática e expansível.

**Principais funcionalidades:**

- autenticação de utilizadores;
- gestão de despesas;
- gestão de categorias;
- anexos em imagens e PDF;
- dashboard financeiro;
- estrutura preparada para funcionalidades PWA;
- base para notificações e sincronização futura.

**Tecnologias:** C#, ASP.NET Core, Razor Pages, Entity Framework Core, Identity, SQLite/SQL Server, JavaScript, CSS.

**Repositório:** [FinancasCasa](https://github.com/Rnarciso15/FinancasCasa)

### Stand-up

Sistema de gestão automóvel desenvolvido com foco em **C#**, **WinForms**, **ASP.NET Core**, **Web API** e arquitectura por camadas.

É um dos meus projectos mais completos, porque explora várias interfaces e separa responsabilidades entre apresentação, aplicação e infraestrutura.

**Principais funcionalidades:**

- gestão de veículos;
- gestão de clientes;
- gestão de funcionários;
- marcação de test-drives;
- filtros por características dos veículos;
- geração de documentos e relatórios;
- múltiplas interfaces para o mesmo domínio.

**Tecnologias:** C#, WinForms, ASP.NET Core, Web API, Entity Framework Core, SQL Server, arquitectura por camadas.

**Repositório:** [Stand-up](https://github.com/Rnarciso15/Stand-up)

### GearUp

Aplicação web desenvolvida com **Blazor**, focada em autenticação, gestão de estado e navegação protegida com **JWT**.

O projecto demonstra a aplicação de conceitos modernos de autenticação e organização de componentes em aplicações web com .NET.

**Principais funcionalidades:**

- formulário de login;
- autenticação baseada em JWT;
- dashboard privado;
- páginas públicas;
- protecção de rotas;
- serviços para autenticação e persistência de token;
- integração com Entity Framework Core.

**Tecnologias:** C#, Blazor, ASP.NET Core, JWT, Entity Framework Core, SQL Server.

**Repositório:** [GearUp](https://github.com/Rnarciso15/GearUp)

### HomeHub

Projecto orientado à criação de uma plataforma doméstica centralizada, associada à ideia de **Home Server/NAS**, organização doméstica e automação residencial.

O objectivo é reunir funcionalidades relacionadas com tarefas, inventário, rotinas, calendário, dispositivos e integrações externas.

**Principais funcionalidades previstas:**

- gestão de tarefas domésticas;
- inventário doméstico;
- calendário e rotinas;
- integração com dispositivos e serviços;
- automação residencial;
- arquitectura modular e extensível.

**Tecnologias previstas:** C#, ASP.NET Core, HTML, CSS, JavaScript, possíveis integrações com APIs e serviços externos.

**Estado:** projecto privado/em desenvolvimento.

O projecto tem uma orientação prática para pequenos negócios que necessitam de organizar processos internos e acompanhar marcações.

**Principais funcionalidades:**

- gestão de clientes;
- gestão de serviços;
- gestão de marcações;

**Estado:** projecto privado/em desenvolvimento.

### Sistema de Gestão de Hotel Java

Projecto académico desenvolvido em **Java**, com foco em programação orientada a objectos, persistência de dados e arquitectura em camadas.

O sistema simula a gestão operacional de um hotel, incluindo clientes, quartos, reservas e utilizadores.

**Principais funcionalidades:**

- gestão de clientes;
- gestão de quartos;
- gestão de reservas;
- autenticação e permissões;
- persistência com SQLite e XML;
- aplicação de padrões DAO e Service Layer;
- arquitectura em camadas.

**Tecnologias:** Java, SQLite, XML, POO, DAO, Service Layer.

**Repositório:** [Sistema de Gestão de Hotel Java](https://github.com/Rnarciso15/sistema-gestao-hotel-java)

### Java Task Manager

Aplicação académica em **Java** para gestão de tarefas, com persistência em XML e geração de relatórios HTML.

É um projecto mais simples, mas útil para demonstrar bases sólidas de POO, validação, tratamento de excepções e organização de dados.

**Principais funcionalidades:**

- criação, edição, remoção e consulta de tarefas;
- estados e prioridades;
- persistência em XML;
- relatórios HTML;
- validação de dados;
- tratamento de excepções personalizadas.

**Tecnologias:** Java, XML, HTML, POO.

**Repositório:** [Java Task Manager](https://github.com/Rnarciso15/java-task-manager)
