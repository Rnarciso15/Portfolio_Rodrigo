Sou programador com especial interesse no ecossistema .NET, desenvolvimento web, bases de dados e arquitetura de software. Gosto de criar aplicações completas, desde a modelação do domínio e persistência de dados até à interface e documentação.

## Executar localmente

### Pré-requisitos

- SDK .NET 10
- Git

### Instalação

```bash
git clone https://github.com/Rnarciso15/Portfolio_Rodrigo.git
cd Portfolio_Rodrigo
dotnet restore
dotnet run --project Portfolio_Rodrigo/Portfolio_Rodrigo
```
